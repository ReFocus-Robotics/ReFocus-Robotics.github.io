# ReFocus project website

This repository hosts the ReFocus project website. Its static source and
media assets can be served from the root of the repository.

To preview locally, run `python3 -m http.server 8000` and open
`http://localhost:8000`.

See the [ReFocus training repository](https://github.com/ReFocus-Robotics/ReFocus)
for RoboCasa365 setup and training.
